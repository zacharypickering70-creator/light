# 烬灯行 · light

中国水墨风格安卓动作肉鸽原型，当前版本 **0.12.0**。

使用 Godot 4.7.2 打开 `game/project.godot`。当前已有竹林家园、雾隐渡、听愿祠、忘川旧市、华山照影、莲心台五章；包含随机开放地图、装备搭配、技能成长、连续闯关，以及古籍剧情演出。

0.12.0 将主角、三类小怪、五位首领和兵器替换为原创低多边形网格。可编辑 GLB 与建模源文件随工程提供，详见 `game/docs/原创模型说明.md`。五章剧情和三结局保持可玩。

安卓安装包见本仓库的 Releases。导出需安装匹配的 Godot Android 模板并配置 Android SDK、Java 和自己的签名。安装包支持 ARM32/ARM64；实际手机性能仍需真机验证。

第三方许可位于 `game/assets/`。用户提供的背景音乐商业授权尚未确认，不能仅因源码公开而假定拥有商用许可。
