# 烬灯行 · light

中国水墨风格安卓动作肉鸽原型，当前版本 **0.13.0**。

使用 Godot 4.7.2 打开 `game/project.godot`。当前已有竹林家园、雾隐渡、听愿祠、忘川旧市、华山照影、莲心台五章主线，以及卷外第六章城隍夜簿；包含随机开放地图、装备搭配、技能成长、连续闯关，以及古籍剧情演出。

0.13.0 新增城隍夜簿、百契债身及原创契秤模型，详见 `game/docs/第六章城隍夜簿.md`。第五章的三种结局保留为第六章的不同来路。

安卓安装包见本仓库的 Releases。导出需安装匹配的 Godot Android 模板并配置 Android SDK、Java 和自己的签名。安装包支持 ARM32/ARM64；实际手机性能仍需真机验证。

第三方许可位于 `game/assets/`。用户提供的背景音乐商业授权尚未确认，不能仅因源码公开而假定拥有商用许可。
