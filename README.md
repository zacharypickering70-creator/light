# 烬灯行 · light

中国水墨风格安卓动作肉鸽原型，当前版本 **0.9.0**。

使用 Godot 4.7.2 打开 `game/project.godot`。当前已有竹林家园、雾隐渡、听愿祠、忘川旧市三章；包含随机开放地图、装备搭配、技能成长、连续闯关，以及古籍剧情演出。

0.9.0 新增忘川旧市、无名判影和三位首领的临终对话。第三章详见 `game/docs/第三章忘川旧市.md`。玩法与剧情见 `game/docs/前两章剧情与演出.md`，历次调整保留在提交历史中。

安卓安装包见本仓库的 Releases。导出需安装匹配的 Godot Android 模板并配置 Android SDK、Java 和自己的签名。安装包支持 ARM32/ARM64；实际手机性能仍需真机验证。

第三方许可位于 `game/assets/`。用户提供的背景音乐商业授权尚未确认，不能仅因源码公开而假定拥有商用许可。
