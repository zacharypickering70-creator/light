# 0.4.1 战斗手感调整

- 命中短暂停顿只保留动作重音，不再中断移动、冷却和战斗更新；闪避立即解除动作停顿。
- 普攻支持 160 毫秒输入缓冲，连续点按可衔接下一击；出招时短暂保留攻击朝向，移动不覆盖瞄准。
- 增加髋部迈步、肩部摆臂、躯干转体和闪避前倾；重复攻击先结束旧兵器动画，避免多段动画争夺同一姿态。
- 敌人受到伤害后出现暖色闪亮和后仰，第三击击退更明显；重斧和连段末击采用重击音效，提高命中声音的辨识度。
- 摇杆死区从 12% 调为 8%，约 80% 推程达到全速，保留轻推慢走。

验证：完整玩法回归、多指操作及三种画面比例检查通过；新增命中时移动、缓冲攻击、迈步关节、敌人后仰、边走边打朝向与闪避测试通过；自动操控完成第一章。开发机渲染无脚本错误。尚未进行安卓真机操作、帧率与发热实测，动作仍为程序化模型动画。
