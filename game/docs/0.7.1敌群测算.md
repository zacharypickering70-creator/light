# 0.7.1 敌群与成长测算

已采用：每波数量在 0.7 基础上增加约 50%（整数四舍五入），由 9～18 只变为 14～27 只；每波血量、伤害成长从 2.5% 提高为 3.5%。跨关额外增强 20%，累计波次不重置。因此下一关首波的同类怪倍率比上一关末波高 24.2%。刷新间隔仍为 6～4 秒，不等待清场；场上上限仍为 65。

## 测试方式

三个相同随机种子分别测试原数量/原成长、增加数量/原成长、增加数量/提高成长，共九场。固定 1/60 秒战斗步长。自动角色使用普攻、闪避、红莲掌、寒江雪、镇山印和满战意绝技，并在升级时学习或提高技能等级。默认兵器衣甲和心法，未购买永久根基；通关首关后继续，打过第二关才主动结算。

不同敌群会改变随机掉落和升级节奏，因此结果包含完整成长循环的影响；不是单独控制经验收入的伤害实验。

| 方案 | 首分钟身边平均敌人数 | 两关通关 | 结束时间范围（秒） |
|---|---:|---:|---:|
| 原数量 / 每波2.5% | 1.62 | 0/3 | 237～289 |
| 数量+50% / 每波2.5% | 2.50 | 3/3 | 266～296 |
| 数量+50% / 每波3.5%（采用） | 2.51 | 0/3 | 193～238 |

原方案三场均在第二关死亡；只加数量后三场均通过两关；同时提高成长后三场均通过第一关，但在第二关死亡。更多怪物增加经验、回复与绝技充能，所以怪多不必然更难。首分钟近身目标增加，技能与绝技有更多目标；后期数值累乘使敌群压力持续上升。

3.5% 方案三场场上同时存活峰值分别为 39、33、34，只证明这些模拟过程未触及上限。没有覆盖所有搭配，也不保证弱势搭配通关。三场不代表真人通关率，结束时间不包含玩家菜单思考时间；尚未进行手机真机帧率和发热测试。

验证：首波 14 只、每波倍率 1.035、跨关递增、状态保留、通关选择、死亡惩罚与触控回归通过。
