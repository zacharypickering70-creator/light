# 烬灯行 0.7 · 连续闯关

安装 烬灯行-0.7-安卓试玩.apk。建议覆盖安装，保留永久根基和已存香火。

## 本次流程

在竹隐居选择兵器、衣甲、灵珠、普攻、绝技、心法和第一招技能，必要时在家中炉台锻造。从传送阵进入雾隐渡。

每关击败首领后选择：
- 继续闯关：血量、灯火、经验、修为、装备强化、技能等级、技能冷却、战意、护盾、增益和残愿保留，进入下一张随机地图。
- 见好就收：带回本次全部香火，返回竹隐居，结束本次成长。

死亡时播放倒地、散光和消散动画，随后回家。本次装备强化、技能、残愿和烬砂清零；本次香火带回一半（向下取整），另一半遗失。家中已有香火与永久根基不扣除。

途中没有兵器架、藏经台或锻造炉，也不能从菜单换装、改普攻、绝技或心法。行囊只显示当前装备。修为升级仍可学习、升级或替换技能；残愿宝箱只提供随机残愿。地图继续自由走动，并不限制成固定道路。

## 波次与跨关成长

普通敌人的血量与伤害倍率为：1.025^(累计波次-1) × 1.20^(当前关数-1)。累计波次只在结束本次行程后重置，跨关不重置。

因此同类小怪每一波比上一波提高 2.5%；第二关第一波与第一关最后一波相比，仅倍率就再提高 23%。第二章另有既有角色血量修正。敌人类型有不同基础血量，不把一只普通怪与另一只重怪直接比较。怪物数量上限仍受控制。

每关首领在比入关时高 6 级，或该关战斗满 6 分钟时出现。升级经验持续递增：40、85、160、260、380、520，之后每级继续增加 140。累计经验、未用学习点和未领取升级机会跨关保留。

当前已有雾隐渡、听愿祠两张剧情地图。第二章后若继续，复用听愿祠素材生成后续随机地图，累计难度继续增长；第三章剧情与专属地图尚未制作。

## 装备与表现

家中可直接选择六件衣甲和六种肩侧漂浮灵珠。衣甲分别强化回复、防护、移动、连段、技能消耗或护盾。灵珠分别强化节能、火焰、连雷、冰控、牵引或护盾，具有独立颜色、符纹、环绕光点与施法反馈。所有武器可搭配。

## 验证

通过 36 种衣甲与灵珠组合生成、装备锁定、经验递增、逐波递增、跨关首波递增、完整状态继承、通关选择、全额归家、死亡动画与半额结算以及重复结算防护检查。多指操作与三种画面比例检查通过；开发机渲染检查通过。

一次自动操作在第二关、累计约 274 秒时死亡并回家，未发生脚本异常。这仅是模拟观察，不代表真人通关率或安卓性能。尚未进行真机持续帧率、发热和操作体验测试。
