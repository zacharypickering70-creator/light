# TapTap Android 发布路线

当前交付是开发试玩原型。先打磨玩法和手机表现，再提交平台审核。

## 制作验收

1. 覆盖低、中、高性能 Android 手机，检查启动、长时间战斗、内存、发热和帧率。
2. 覆盖 16:9、全面屏、平板、异形屏，验证多指、旋转、来电、切后台和返回键。
3. 验证首次安装与版本更新，开展真实玩家试玩，调整技能搭配、敌群和 Boss 难度。
4. 完善模型、动作、音效、碰撞与教学，制作真实游戏截图和视频。

## 平台流程

完成开发者认证与游戏创建后，准备名称、图标、说明、截图、实机视频和 APK，按阶段进行页面展示、测试或正式发布。页面展示和开放下载是不同阶段。[新建和管理游戏](https://developer.taptap.cn/docs/store/release/publish/create-game/)

正式分发前需核对适用的版号、APP 备案、隐私政策、实名认证与防沉迷要求，准备素材授权。涉及内购计费时需按平台要求提供版号；不能把免费或单机理解为免除所有资质。适用范围以发布时的审核与相关规定为准。[TapTap 游戏审核规范细则](https://developer.taptap.cn/docs/store/release/publish/agree/)

可结合实际测试计划，咨询测试游戏核准辅助证明是否适用。[APP 核准常见问题](https://developer.taptap.cn/docs/store/release/policy/filing-faq/)

发布前还需确定正式包名、发行签名与版本规则，核实权限和第三方组件，准备与实际行为一致的隐私说明。本次未创建开发者账号、提交资质或上传 APK。
