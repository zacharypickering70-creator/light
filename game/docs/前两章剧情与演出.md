# 0.8.0 · 前两章剧情与演出

每章入场与首领战后，播放线装古籍式残卷。墨字用 1.1 秒浮现，按篇幅停留，随后用 1.3 秒淡出并翻页；玩家可触屏翻页或略过。阅读期间暂停战斗、刷怪和局内计时。第一章配渡船、江波图纹，第二章配莲纹；战后读完再选择继续或归家。

## 第一章：雾隐渡

陆照川携宝莲灯灯芯离家，留下让徒弟沿灯签寻人的嘱托。玩家来到雾隐渡，发现船夫缚舟锁住渡船，反复呼唤女儿。

旧信交代：洪水当夜，他先救下一船人，答应下一趟接女儿，回来却已找不到旧岸。有人许诺只要无人离开，失散之人便会回来。他遂以等待为名封锁渡口。师父曾默许他把希望寄托在灯上，也承认自己的沉默成了锁人的绳。

击败缚舟后，他问自己若走了，谁来接女儿。玩家留下渡灯：“灯可以等她。其他人该过河了。”缚舟终于推船入水。船篷里的旧笺与祠中愿签共同指向听愿祠；陆照川请求徒弟不要再替自己许诺。

主题：承认一个人的悲伤，也要让其他人有继续生活的自由。女儿的下落尚未得到证实；破关不等于让所有失去都得到补偿。

## 第二章：听愿祠

祠前求愿者反复叩首。他们曾求亲人归来、求安眠，如今连自己为何祈愿也渐渐忘记。百愿娘娘许诺免去失望，师父留下的莲纹却指向愿簿。

愿簿记下娘娘的转变：灾后收殓亡者，随后收走噩梦，最后连悲伤、拒绝和离开的念头一并收走。玩家可在两处唤醒求愿者，听到他们愿意记住失去、自己选择离开的心愿。

击败娘娘后，她仍问成全众人的愿望何错之有。玩家揭开被抹去的一行：“他们也该能说，不愿。”愿契解除后，有人哭、有人留下、有人离开；战后文字会根据本局是否救人作出回应。

殿后的灯座和手札揭露：陆照川亲手续过灯芯，明知这盏灯在留人。他保护的孩子性命系于灯中，他以保住一命为由拖延放手。末页夹着“忘川”引路签，留下下一章的方向；孩子身份和师父最终选择仍未揭晓。

主题：安慰应保留人的选择。慈悲一旦替人决定一切，也会伤害自己想保护的人。

## 叩首人群与定身

- 共 38 位求愿者：祈愿门 6 位、两处祈愿点各 8 位、正殿 16 位。每人动作相位和速度不同，循环俯身叩首。
- 人群列在两侧，保留中央走位空间；不计入敌人数、不参与索敌、不提供经验。
- 唤醒求愿者后，本处人群停止叩首，起身离场。击败首领后，全体解除愿契；先留出 2.5 秒展示起身，再进入古籍结尾。
- 金圈内前两秒按每秒 8 点回血。连续停留满两秒定身 1.2 秒，头顶显示朱底金色“定”字。定身时仍可攻击和施法。
- 踏影可立即解缚，提供 0.8 秒愿缚宽限。提前离圈也能避免触发。定身到时自动结束；同一次持续停留不会反复刷新定身。
- 金圈存在 4.5 秒，最后 1.5 秒转红预警，到时爆裂。已有的敌人数量和成长曲线沿用 0.7.1。

目前只有前两章的专属剧情和地图。后续“愿境深处”继续使用已有素材随机生成，不代表忘川章节已经实现。
