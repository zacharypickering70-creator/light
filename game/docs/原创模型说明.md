# 原创角色与兵器 · 0.12.0

本版采用为《烬灯行》制作的低多边形网格，强调俯视手机画面中的轮廓与配色。它是风格化模型，不是写实高精度角色。

## 模型清单

- 提灯人：斗笠、交领衣、红披风、分段四肢和手部挂点。
- 符面刀客、青衣咒师、负甲重卒：符纸、尖冠、重甲与不同兵器轮廓。
- 缚舟：旧斗笠、绳索和船桨。
- 百愿娘娘：宽裙、莲冠、背轮与莲杖。
- 无名判影：判冠、面具、判简。
- 二郎显圣真君：天眼、银甲、翎饰、三尖兵器。
- 陆照川：发髻、胡须、衣袍、守灯笔与提灯。
- 练习人偶：沿用可练习功能的关节模型。

五种玩家兵器为朴刀、青锋剑、红缨枪、盘龙棍、开山斧；另有五件首领道具独立文件。刀刃使用轮廓与中脊构成斜面，枪缨和披风为网格条带。

## 编辑与重建

`assets/models/` 包含 20 个 GLB、网格清单和游戏用水墨分面材质。GLB 可导入支持 glTF 的建模软件。角色包含 Idle、Walk、Attack 基础节点动画，属于分段刚性关节，不是蒙皮骨骼或动作捕捉。

`art_source/build_models.py` 保存全部原创轮廓、顶点、颜色、层级和动画的生成源。使用 Python 运行即可重建 GLB，仅依赖标准库。模型没有使用外部人物或兵器网格。

运行时通过 `model_library.gd` 统一挂接；游戏继续使用现有动作节奏驱动关节，保持攻击数值与判定范围。导入文件中的基础动画用于后续编辑参考，不会同时播放而覆盖战斗姿态。

衣甲切换改变衣袍颜色，灵珠、技能符纹与既有特效继续保留。小怪按三种战斗类型共用相应网格，五位首领各用独立模型。

## 预算与检查

每个角色约 1600～2400 个三角面，7～8 个网格部件；独立兵器 60～368 个三角面。相同小怪共享网格和水墨材质。准确统计见 `assets/models/inventory.json`。

专项检查覆盖全部资产导入、节点动画、顶点颜色、面数、手部随动、武器替换、六种衣甲颜色、65 个群怪模型、受击和死亡归家。第三至第五章首领流程回归通过。开发机检查模型展示和游戏内画面；这些检查不代表安卓真机帧率、发热或流畅度结论。
