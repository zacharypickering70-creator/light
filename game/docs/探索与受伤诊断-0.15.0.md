# 探索奖励与第二章受伤诊断 · 0.15.0

## 新的探索收益

每个战斗场景增加 3 份武学遗卷，分布在第 1、3、5 处地标附近的随机可行走位置，三份招式互不重复。随机源由地图种子独立派生，不占用战斗随机数；安全家园不生成遗卷。

靠近 14 米后显示遗卷名称，靠近 3 米交互。可免费学入已开放的空槽，或替换一个技能；同名遗卷使该招提升一级，满级时转为 1 学习点。最多三个技能，第二、三槽仍在修为 3、5 开放。替换后的招式从 1 级开始，原冷却不会清空。不作选择时遗卷留在原地；确认后只消耗一次。跨章保留已学招式，归家／死亡重置本局成长。

原有五处遗珍改为三处残愿宝箱、两处行旅补给箱。补给箱恢复 30% 最大气血、40 灯火，并获得 20 烬砂；残愿箱沿用 20 烬砂与三选一残愿。遗卷有纸卷外形，宝箱增加箱盖与箍带。新增奖励不预先标在小地图上。

## 受伤记录

正式伤害结算增加按章节和来源统计：近战杂兵、重甲、远程小怪弹幕、首领近战／弹幕／其他攻击。记录受击数、护盾吸收、实际损失生命、单次穿盾伤害峰值及最后受伤来源。无敌期拒绝的攻击不计入，过量伤害不计入实际生命损失。记录只在内存中用于测试，不上传，不写玩家存档。

修改前的 20 局中有 18 局死亡，其中 12 局最后一击来自第二章远程小怪弹幕，另有 2 局来自第一章远程弹幕。不能仅凭最后一击判断此前全部伤害来源；原始 JSON 同时保存完整分类累计。

第二章远程怪原先每次攻击都有三发扇射，第一章只有单发，同时沿用跨章血量／伤害增长。预警只在怪物脚下画圈，无法表达射击方向。该差异叠加了数值和弹幕覆盖压力。

本版第二章改为两次单发后一次三发扇射，瞄准蓄力由 0.6 秒延至 0.9 秒。各章远程怪都增加方向预警线，线数与这一轮弹数一致，攻击落下或怪物死亡时清除。敌人数量、生命、伤害、波次增长和玩家升级需求不变。

结束可能是死亡或完成两章，不能将时长直接解释为生存能力。每套仅五个种子，行为改变也会改变后续战斗与残愿选择，不能认定每套搭配都得到增强。结果支持继续观察新的射击空隙，尚不能宣称整体平衡成熟。

测试操作者会躲近战圈，但没有针对弹道规划闪避路径，也不领取探索奖励。因此测试能定位压力来源，不能把死亡比例当成人类胜率，或把新增遗卷、宝箱的收益当作已被这 40 局测量。探索收益另以功能测试验证，实际绕路收益需要手机试玩。
