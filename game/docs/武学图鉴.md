# 烬灯行 0.4 · 武学图鉴

在竹隐居点击右上“武学”，或靠近藏经台点交互。所有兵器均可搭配下列武学。

| 名称 | 效果 |
|---|---|
| 断岳刀法 | 前方横斩，第三击重击；击败燃烧敌人引爆周围。所有兵器可用。 |
| 流星快打 | 攻击间隔缩短 20%，单击伤害降低 15%；第三击发出剑气。所有兵器可用。 |
| 长虹贯日 | 攻击距离 +35%，窄幅穿刺；对减速敌人增伤 35%。所有兵器可用。 |
| 八方扫叶 | 360 度横扫，单击伤害降低 15%；第三击击退敌群。所有兵器可用。 |
