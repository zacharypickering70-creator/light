# 第五章 · 莲心台

0.11.0 实装主线终章。第四章通关后继续进入莲心台，等级、经验、装备、技能、冷却、血量与累计波次沿用同一次行程。

## 故事骨架

主角沿二郎神留下的界隙抵达师父的最后一重愿境。这里保存着旧院、温茶和不必告别的一天。陆照川想把徒弟留在家里；前四章被留下的人却一直在门外等候自己的归路。

师父并非被邪物操控。他承认愿境的代价，却习惯把偿还推到明天。主角这一次要做的，是先听清受影响者的心愿，再与师父交锋，决定灯的去留。

入梦门、归人灯市、长明亭、照心池、守门庭、断契碑、莲心台共七处随机地标，保持开放行走。场景加入灯阵、莲瓣石台、问愿人、旧院幻景。

## 探索与引导

三种心愿分布在灯市、长明亭和守门庭：想醒来的归人、尚想暂留的留灯人、愿意承担但不替人许诺的守门人。靠近后交互；主线记录说明目标、心愿进度和首领应对方法，途中仍不能换装或锻造。

照心池家书回忆师父如何教徒弟忍痛；断契碑说明三条路的代价。心愿记录按人物去重。听完三种心愿解锁「留门」，无需按固定路线探索，也不要求前几章选择某个答案。战后可补听遗漏的心愿，避免一次漏看永久失去结局。

## 三阶段终战

首领陆照川在本境升六级或战斗六分钟后出现。持笔与灯，采用金褐衣袍。阶段在下一次起招时按剩余生命切换，不会在已出现的预警中途替换伤害区域。

1. 落笔成契（生命高于 66%）：三处朱印封住横向区域。预警 1.65 秒，圈半径 2.5，中心间距 5.8；向侧前方离圈，落笔后反击 1.7 秒。
2. 旧愿重现（33%～66%）：周围浮现留灯人的残影，愿环半径 2.8～7.3 造成伤害。可进入青色内圈，或退到外圈之外；预警 1.55 秒，破绽 1.7 秒。
3. 旧院问心（不高于 33%）：战场浮现旧院地面、门与树影，角色位置和属性不重置。笔锋锁定直线，长条宽 3.6、直段长 12，两端半径 1.8。预警 1.4 秒，向两侧闪避，破绽 2.1 秒。

预警范围与伤害范围一致；边缘朱印整体内移，保持分离。幻景不新增阻挡碰撞，不会突然把玩家困入墙内。三阶段使用不同地面表现与「契／愿／归」提示。

## 灯前问答

陆照川：我只想再听你喊一声师父。后来每一次灯将灭，我都说，再等一晚。

提灯人：师父。我回来了。可他们也有人在等。

陆照川：若灯熄了，你会不会也走？

提灯人：会。我也会怕。可你不能因为怕，就替所有人把门锁上。

三圣母的灯中神念指出：灯能照路，不能代人走路。续灯须承认所借，破灯须承担所失；留门须先听清门两边的声音。

陆照川终于交出替徒弟回答的权力。玩家可逐句阅读、补全文字或略过；略过对话仍会进入结局选择。

## 三个结局

**续灯**：接过灯，眼前愿境得以保留，借命之契仍在。主角必须面对自己将如何回答下一个想走的人。它承认眼前的安慰，也保留代价。

**破灯**：折断借命之契，真实的人归家，愿境和主角借灯而成的身形消散。师父终于没有再点灯挽留。故事保留失去，不把告别写成毫无代价的胜利。

**留门**：听过醒来、暂留、承担三种心愿后，停下借命，归还名字，门由每个人自己跨过。愿境只用余火供暂留者告别，不承诺永远存在。主角交还反复借形的保障，师父留下偿还责任。

结局通过莲纹古籍渐显、停留、淡出。选择完成后不会被连续点击覆盖，也不会重复发放通关奖励。本版结局属于本次行程，没有跨周目的结局收集册。

## 收卷之后

归家可带回全部本次香火，并结束局内成长；0.13.0 起继续进入卷外第六章《城隍夜簿》，之后可挑战随机「余烬回响」，保留状态、敌群继续变强。卷外内容保留已选结局，也不重复师徒终章抉择。死亡仍执行原有动画、半额香火与归家流程。
